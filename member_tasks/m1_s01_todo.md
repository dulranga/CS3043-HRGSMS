# SkyNest HRGSMS

A simple project map of what each member owns and builds. Details live in each member's task file.

## Member 1 — Dulranga (accounts, guests, and shared foundations)

- [ ] Agree the basic rules with the team (IDs, dates, identity numbers, account links)
- [ ] Build branch and role tables
- [ ] Build user accounts and staff records
- [ ] Build guest and guest-account records
- [ ] Build the activity log (who did what)
- [ ] Build the settings table (non-money settings only)
- [ ] Add login / logout for staff and guests
- [ ] Add permissions (who can do what, in which branch)
- [ ] Add guest sign-up and account linking
- [ ] Add guest profile management (staff + self-service)
- [ ] Add staff-account admin
- [ ] Build the login / sign-up / guest screens
- [ ] Link guest bookings into their account summary
- [ ] Build the billing-policy table (pricing rules)
- [ ] Add branch-record admin

## Member 2 — Imandi (rooms and bookings)

- [ ] Build room types, amenities, and the link between them
- [ ] Build rooms and room blocks (dated outages)
- [ ] Build bookings and booking status history
- [ ] Build booking room lines (each room, its own dates/rate)
- [ ] Build room assignments (which line is in which room)
- [ ] Rework old single-room data into the multi-room model
- [ ] Prevent double-booking / overlapping stays
- [ ] Build availability search
- [ ] Build booking create / edit / view for staff and guests

## Member 3 — Kulunu (check-in and services)

- [ ] Build services and service-usage records
- [ ] Build room-condition history
- [ ] Add per-room check-in during a stay
- [ ] Record service usage against a checked-in stay
- [ ] Keep room-condition changes tracked and audited

## Member 4 — Chamikara (billing and payments)

- [ ] Agree the billing rules with the team
- [ ] Build invoices and invoice lines
- [ ] Build payments (including refunds)
- [ ] Handle checkout, cancellation, and no-show
- [ ] Enforce zero-balance checkout
- [ ] Keep finalized invoices locked and correct

## Member 5 — Thusath (reports and admin screens)

- [ ] Build the five required reports (occupancy, billing, services, revenue, top services)
- [ ] Build report filters and exports
- [ ] Build admin screens for users and branches
- [ ] Build the audit-review screen
- [ ] Build the settings and billing-policy screens
