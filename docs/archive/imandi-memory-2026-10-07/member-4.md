Whole-booking cancellation requires every line to be in `BOOKED` status and before cutoff; if any line is ineligible, the whole operation fails with 400 (`NOT_ALL_LINES_ELIGIBLE`) and rolls back atomically. Default repeated cancellation returns 409 Conflict (`LINE_ALREADY_CANCELLED`), while idempotent retries (`?idempotent=true` or `idempotency-key`) return 200 OK with `repeated: true`.
